# 按前缀忽略消息 (nekro_llm_ignore_prefix)

NekroAgent 插件：命中指定**前缀 / 正则**的消息**照常记录到历史、其它插件照常收到**，
只是**不唤起 LLM 回复**。适用于"让某类消息给工具型插件处理、但不想让 AI 接话"的场景。

版本：**1.0.0**　作者：**NTidal**

---

## 与 NA 内置过滤配置的区别

| | 内置 `AI_IGNORED_PREFIXES` / `AI_CHAT_IGNORE_REGEX` | 本插件 |
|---|---|---|
| 拦截层级 | **入口级**：消息不落库、不进插件、不触发 LLM | **钩子级**：照常落库、其它插件照常收到，仅不唤起 LLM |
| 其它插件可见性 | ❌ 收不到 | ✅ `mount_on_user_message` 照常触发 |
| 历史记录 | ❌ 整条消息消失 | ✅ 保留（供后续检索） |
| 典型用途 | 彻底屏蔽噪音 | 消息交给 gscore 桥接、图库指令等工具型插件处理 |

---

## 功能

- 📝 **前缀匹配**：消息以配置的任一前缀开头即命中（区分大小写）；
- 🔣 **正则匹配**：`search` 语义，可用于后缀 / 包含匹配；编译失败自动跳过并记日志，不影响其它规则；
- ✂️ **前导空白容忍**：可配置匹配前去除前导空白（`"  #提示"` 也能命中 `#提示`）；
- 📌 **前缀优先于 @机器人**：@ 了机器人但命中前缀时仍不触发（可关闭）；
- 📺 **频道范围控制**：支持"仅在指定频道生效"与"排除指定频道"（排除优先）；
- 📋 **命中日志**：每次命中写插件日志，方便确认规则是否生效。

---

## 已知边界

`BLOCK_TRIGGER` 只拦截"本次触发"。命中前缀的消息**仍会出现在后续对话的
Recent Messages 历史里**（之后被别的消息触发时 LLM 依然能读到这段记录）——
NA 没有暴露历史渲染钩子。若需要"对 LLM 完全不可见但插件仍可见"，
必须改核心（落库后跳过触发 + 历史渲染过滤），本插件做不到。

## 安装

1. 将 `llm_ignore_prefix/` 目录放入 NekroAgent 插件目录（`plugins/workdir/`），或在 NA WebUI 打包上传；
2. **完全重启 NekroAgent**；
3. 在插件配置中填写 `PREFIXES`（或 `REGEX_PATTERNS`），保存即生效；
4. 发送一条命中消息，观察 AI 不回复且插件日志出现「命中忽略规则」。

> 注意：本插件必须在 `PLUGIN_ENABLED` 启用列表中才会生效——
> 只部署不启用时**不会有任何报错**，规则静默不工作。

## 配置项

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `ENABLED` | `true` | 总开关，关闭后所有规则都不生效 |
| `PREFIXES` | 空 | 忽略的消息前缀列表（区分大小写；留空则不拦截） |
| `REGEX_PATTERNS` | 空 | 忽略的消息正则列表（`search` 语义，可用于后缀/包含匹配） |
| `TRIM_LEADING_WHITESPACE` | `true` | 匹配前去除前导空白 |
| `PREFIX_WINS_OVER_AT` | `true` | @机器人也命中前缀时仍不触发；关闭则该消息正常触发 |
| `INCLUDE_CHAT_KEYS` | 空 | 仅在这些频道生效；留空 = 所有频道 |
| `EXCLUDE_CHAT_KEYS` | 空 | 这些频道不应用规则（优先级高于 INCLUDE） |
| `LOG_HITS` | `true` | 命中时写插件日志 |

## 使用示例

**配合 GsCore 桥接（典型场景）**

想让 `core 帮我查体力` 这类消息只给 GsCore 桥接处理、AI 不掺话：

- `PREFIXES` 填 `["core", "gs", "体力"]`（与 GsCore 桥接的 `GSCORE_COMMAND_PREFIXES` 保持一致）
- 消息照常被桥接插件转发给 gsuid_core，AI 不回复

> 也可以直接用 GsCore 桥接自带的混合模式（`HYBRID_MODE`），两者取其一即可；
> 本插件的优势是规则集中管理、支持正则与频道白名单。

**自定义记录指令**

- `PREFIXES`：`["记录：", "#记"]`
- `REGEX_PATTERNS`：`["^(早|晚)安打卡"]`

---

## 工作原理

挂载 `mount_on_user_message` 钩子，命中规则时返回 `MsgSignal.BLOCK_TRIGGER`：
消息照常落库、其它插件照常收到，仅阻止 LLM 触发。正则编译结果带缓存，
非法表达式只跳过自身并记错误日志，不影响其它规则与插件。
